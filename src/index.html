KVMGUI

Lightweight QEMU VM Manager

A VMware Workstation-style GUI for QEMU/KVM.
Built with Zig 0.16 + FLTK 1.4 + vanilla HTML/CSS/JS.

No libvirt dependency — direct QMP control.
